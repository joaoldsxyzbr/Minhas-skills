# Using Minhas Skills

Use this router when a task clearly matches a skill in this collection. For a simple question or small direct edit, answer or act directly without adding process.

## Choose the workflow

- New feature or unclear product idea: brainstorming; for a new product experience, use product-design-ideation.
- Agreed requirements that need an implementation plan: writing-plans; carrying out an agreed plan: executing-plans.
- Feature or bug fix: test-driven-development.
- Failure or unexpected behavior: systematic-debugging.
- Before reporting technical work as complete: verification-before-completion.
- Product UX research or design direction: product-design-ideation; audit an existing flow: product-design-audit; implement a reference and validate rendering: product-design-implementation-qa.
- Cloudflare platform work: cloudflare-platform; D1 schemas, migrations, bindings, or queries: cloudflare-d1.
- GitHub repositories, branches, commits, or pull requests: github-workflows; isolate substantial work: using-git-worktrees; review a diff: code-review; prepare completed work for handoff or integration: finishing-branch.
- Creating or auditing a skill: skill-authoring-audit.
- Evidence-heavy or current questions: deep-research.

Use only the relevant workflow. Do not invoke every skill on every turn. Follow the user's explicit scope and preferences; ask only when a missing decision would materially change the result.
