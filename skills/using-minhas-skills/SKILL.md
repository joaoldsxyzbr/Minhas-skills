# Using Minhas Skills

Use this router when a task clearly matches one of the skills in this collection. For a simple question or a small direct edit, answer or act directly without adding process.

## Choose the workflow

- New feature, unclear request, or product idea: `brainstorming` or `product-design`.
- Implementation task with agreed requirements: `writing-plans`, then the project's implementation and verification workflow.
- Feature or bug fix: `test-driven-development`.
- Failure or unexpected behavior: `systematic-debugging`.
- Cloudflare platform work: `cloudflare-platform`.
- Repository, branch, commit, or pull request work: `github-workflows`.
- UX research or interface evaluation: `product-design`.
- Evidence-heavy or current question: `deep-research`.
- Before reporting a technical change as done: `verification-before-completion`.

Use only the relevant workflow. Do not invoke every skill on every turn. Follow the user's explicit scope and established preferences; ask a concise question only when a missing decision would materially change the result.
