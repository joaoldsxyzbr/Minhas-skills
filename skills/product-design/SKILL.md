# Product Design

Apply the [shared workflow rules](../using-minhas-skills/references/workflow-rules.md); read once and reuse for this task.

Use this skill to select the right focused product-design workflow. For a straightforward UI change with clear requirements, implement it directly.

- New experience or substantial redesign: use [product-design-ideation](../product-design-ideation/SKILL.md).
- Critique or improve an existing interface or user journey: use [product-design-audit](../product-design-audit/SKILL.md).
- Implement a supplied mockup, screenshot, or reference, or verify a UI change: use [product-design-implementation-qa](../product-design-implementation-qa/SKILL.md).

Keep findings grounded in available evidence. Do not claim research, usability, accessibility, or visual validation that was not performed.
