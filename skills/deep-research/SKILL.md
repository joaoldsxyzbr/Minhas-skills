# Deep Research

Use when the user asks for in-depth research, a comparison, a decision with meaningful consequences, or facts likely to have changed. Keep simple stable questions lightweight.

## Define the question

- Convert the request into a focused question and decision criteria.
- Record scope, date range, region, and constraints that affect the answer.
- Separate subquestions so each can be answered with evidence.
- If a key scope choice is missing and would change the findings, ask one targeted question. Otherwise state the working assumption.

## Gather evidence

1. Search for primary sources first: official documentation, regulations, research papers, product pages, company filings, datasets, or direct statements from responsible organizations.
2. Use independent reputable sources to corroborate contested claims and add context.
3. Check publication dates and event dates separately. For unstable information, verify the latest available status.
4. Open and read the relevant source rather than relying only on search snippets.
5. Keep a source ledger with claim, source, date, and confidence.
6. Distinguish source facts, inference, estimates, and unresolved disagreement. Do not fill gaps with plausible-sounding guesses.

## Compare and synthesize

- Apply the same criteria to each option.
- Explain material tradeoffs, exceptions, and who each option suits.
- Cite evidence close to each factual claim. Prefer concise paraphrase over long quotations.
- State the conclusion directly and explain which evidence most affects it.
- Include limitations when evidence is thin, sources conflict, or the question cannot be answered conclusively.

## Deliver

Lead with the answer, followed by the evidence and practical next step. Include a compact comparison table when it improves clarity. Provide sources with useful titles, links, and dates. Never fabricate a citation, quote, search, or verification.
